# 🚗 자동차 경주

입력횟수만큼 자동차들이 무작위로 전진하거나 정지하며 최종적으로 가장 멀리 이동한 자동차를 우승자로 출력합니다.
<br><br>

## 프로그래밍 요구사항

```text
- indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다. 2까지만 허용한다.
  - 예를 들어 while문 안에 if문이 있으면 들여쓰기는 2이다.
- 3항 연산자를 쓰지 않는다.
- 함수(또는 메서드)가 한 가지 일만 하도록 최대한 작게 만들어라.
- Jest를 이용하여 정리한 기능 목록이 정상적으로 작동하는지 테스트 코드로 확인한다.
```

## 구현 기능 목록

- [x] **자동차 이름 입력 처리**
  - [x] 사용자로부터 자동차 이름 문자열을 입력 받는다. <br>
        ex) `'pobi, woni, jun'`
  - [x] 입력 받은 문자열에서 각 이름의 앞뒤 공백을 제거한다.

- [ ] **자동차 이름 파싱**
  - [ ] 쉼표(`,`)를 기준으로 이름들을 분리해 배열로 변환한다.

- [ ] **자동차 이름 검증**
  - [ ] 각 이름은 **5자 이하**만 허용한다.
  - [ ] 구분자는 **쉼표(`,`)**만 허용한다.
  - [ ] 빈 문자열(`''`) 또는 이름이 공백일 경우 예외로 처리한다.

- [ ] **시도 횟수 입력 처리**
  - [ ] 시도 횟수를 입력받는다.
  - [ ] 허용 범위: **0 이상의 정수**
  - [ ] **정수 이외의 입력** (문자, 소수 등)이나 **음수**가 입력되면 예외처리된다.

- [ ] **라운드 진행 (전진/정지)**
  - [ ] 입력받은 시도 횟수만큼 라운드를 반복한다.
  - [ ] 매 라운드마다 각 자동차에 대해 무작위 값을 생성한다.
  - [ ] 무작위 값이 **4 이상이면 전진**, **3 이하면 정지**한다.
  - [ ] 매 라운드마다 각 자동차의 전진 상태를 출력한다.

    ```text
    pobi : --
    woni : ----
    jun : ---
    ```

- [ ] **우승자 계산 및 출력**
  - [ ] 모든 라운드가 종료되면 가장 멀리 간 자동차를 계산한다.
  - [ ] 우승자가 한 명이면 해당 이름을 출력한다. <br>
        ex) `최종 우승자 : pobi`
  - [ ] 여러 명이면 `,`로 연결하여 함께 출력한다.<br>
        ex) `최종 우승자 : pobi, jun`

<br>

## 예외

- [ ] **이름 관련**
  - [ ] 이름이 6자 이상인 경우
  - [ ] 입력 문자열이 비어있거나 공백 이름이 포함된 경우
  - [ ] 쉼표(`,`)가 문자열의 앞뒤에 위치한 경우
  - [ ] 쉼표(`,`) 이외의 구분자를 사용한 경우

- [ ] **시도 횟수 관련**
  - [ ] 입력이 비어있거나 공백인 경우
  - [ ] 정수가 아닌 값 입력 (문자/소수 등)
  - [ ] 음수 입력

